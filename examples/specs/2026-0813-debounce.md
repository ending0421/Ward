# 任务规格示例：防抖工具函数（specs/<task-id>.md）
#
# 用法（spec §3-M4）：
#   1. 任务开始前，由人（或人审 Agent 草案）编写本文件并随代码评审入库；
#   2. 每个 commit message 引用条款号，如 `[spec:a2]`；
#   3. 内环预检：`ward form-check --spec specs/2026-0813-debounce.md`
#      外环裁决：CI 中同一命令以 fail-closed 姿态执行（P7）。
#
# 断言种类（内环语义）：
#   no_new_dependency  → 本地可判（依赖清单 diff）
#   max_files_changed  → 本地可判（diff 文件数）
#   must_pass          → deferred（全量测试仅 CI 外环裁决）
#   behavior_diff      → deferred（golden/差分测试仅 CI 外环裁决）
#   api_compat         → unknown（类型/二进制级判定需 CI 外环逐语言工具）
