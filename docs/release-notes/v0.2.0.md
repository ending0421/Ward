# Release v0.2.0

> 治理数据与校准版：Ward 开始回答"它到底有没有用"——客观采纳推断、
> 黄金集标注、Wilson 置信区间校准、趋势快照与治理报表全部上线。
> 同时确立 AI 提交标记约定，Ward 从此能区分 AI 与人类提交。

## Highlights

- **客观采纳通道 `ward infer`**：不再信任 Agent 自报——观察 advisory 之后
  的提交，区分 `accepted`（复用+新增调用边）/ `rejected`（引入相似符号）/
  `reused-ish`；`ward setup-hooks` 安装 git post-commit 自动推断；
- **黄金集标注 `ward label`**：match 级交互标注（展示查询意图、代码片段、
  行号），相似度随标注落库——spec §9 周级校准的第一块拼图；
- **`ward calibrate`**：0.80–0.98 阈值扫描 × **Wilson 95% 置信区间** +
  样本量警告（"1 条标注 → CI 21%–100%，不可信"），只建议、不落盘；
- **`ward stats` 治理报表**：双通道采纳率 + 背离报警、重复簇趋势、
  约束衰减提示、每日幂等快照；JSON 三层结构（meta/current/series）
  为看板预留；
- **AI 提交标记约定**：`[ai]` 前缀 + `Co-authored-by` trailer 双标记，
  词边界匹配（`gmail` 不会误伤）；本版起 Ward 仓库自身提交开始带标记。

## Breaking Changes

- **索引 schema v3 → v4**：新增 `labels` 与 `snapshots` 表。首次打开
  旧索引时 F1 自动整库重建（约 1s @ 500 符号），**仅损失速度、无数据
  风险**，无需手动迁移。
- `ward label` 的 `--repo` 参数位于子命令内（`ward label next --repo .`）。

## Features

### 推断采纳通道（spec §3-M1 双通道的客观半边）

- `ward infer`：对每条未推断 advisory 找 ts 之后的第一个提交，
  diff 对比——引入与 top-1 相似（simhash ≥ 0.8）的符号 → `rejected`；
  未引入但新增调用边 → `accepted`；两者皆无 → `reused-ish`；
  无后续提交 → `unknown`。秒级时间戳边界问题已文档化；
- `ward setup-hooks [--remove]`：幂等安装/卸载 git post-commit
  （fail-open，永不阻塞提交）。

### 黄金集与校准（spec §9）

- `ward label next / set`：候选解析含旧格式（裸 matches 数组）兼容；
- `ward calibrate [--json]`：每档位 yes/no 计数、precision、Wilson CI、
  样本充分性标记（≥20 条），建议强阈值为 `ci_low ≥ 0.60` 的最高档。

### 治理报表

- `ward snapshot [--json]`：每日幂等（同日覆盖）；
- `ward stats [--json]`：`adoption`（五计数 + 背离）、`clusters`、
  `symbols`、`labels`、`contract_runs`、通过率与衰减提示、四条
  series（symbols/duplicate_clusters/advisories/labels）。

### 提交来源识别

- `is_ai_commit`：`[ai]` 前缀（大小写不敏感）或 `Co-authored-by`
  trailer 命名词（claude/codex/deepseek/gpt/copilot/cursor/agent/
  anthropic/openai…），**从不猜测**——无标记即"未知"。

## Fixes

1. **result_json 存储缺陷**：spot 此前把裸 matches 数组写入
   `advisories.result_json`，导致 infer/label 解析失败、相似度静默丢失。
   现存储完整 SpotResult（含 query/as_of/stale），并为旧数据提供
   兼容解析器 `parse_spot_payload`；
2. **doctest 伪代码编译失败**：infer.rs 文档中的推断语义伪代码块被当
   Rust 编译（CI 质量门拦截了首个 v0.2.0 发布，这正是门禁的意义）。
   已标记为 ```text 块；
3. **安装器 latest 解析**：GitHub API 限流时回退 v0.1.0（陈旧二进制）。
   改为 git 协议取最新 tag（无速率限制）；
4. SQL 空集 SUM 返回 NULL 导致报表崩溃——全部 COALESCE。
