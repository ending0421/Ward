# Release v0.1.0

> 首个公开版本——Ward 从设计规格走向完整可用的工程：五语言护栏引擎、
> 双环架构（内环 advisory / 外环 fail-closed）、一键发布流水线全部就位。

## Highlights

- **五语言首选矩阵落地**：Rust / Kotlin / Swift / Java / Objective-C 五个
  tree-sitter 语法全部编译接入，LanguageSpec 表驱动（加语言 = 加一行 spec，
  零引擎改动）；
- **M1 Spot 四层指纹 + 块级指纹**：L0 原文哈希 / L1 归一化结构哈希 /
  L2 Charikar simhash / L3 嵌入接口，外加滑窗语句块指纹——从"精确克隆"
  到"函数内抄段落"全覆盖，且文本证据永不强提示（防假阳性）；
- **M2 Replay 确定性变更摘要**：符号级六类变更分类（含 doc-only 文件级
  检测）、影响面下界（"至少 N 处"）、风险标记，每条事实锚定 `path:line`；
  LLM 叙述层逐句锚点校验（F6 结构化回退）；
- **M3 Catch / M4 Form Check**：内环 lint 预检（秒级、无 Docker）与外环
  Docker 沙箱裁决（断网/只读/cap-drop 可测）；规格断言 + 逐语言 api_compat
  编排（cargo-semver-checks）+ M4-b 意图漂移软比对；
- **治理基座**：M5 context_card（调用方反向索引）、M6 重复簇聚类（鸽笼
  分桶剪枝 + 暴力一致性验证）、增量索引（未变文件 0.02s 跳过）。

## Breaking Changes

- 无（首个版本）。

## Features

### 引擎（ward-core，19 模块）

- 配置（fail-open 默认值）、五语言注册表、指纹、The Rack SQLite 存储
  （schema v3，F1 版本不匹配自动重建）、索引器（符号级 mention 边）、
  BM25+simhash 检索、per-file 新鲜度协议、M2 确定性 diff、M4 规格断言、
  M3 验证闭环（含可注入 docker 二进制的沙箱运行器与安全姿态断言）。

### CLI（`ward` 单二进制）

- `init / index / spot / replay / catch-run / verify / form-check /
  compat-check / intent-check / card / clusters / action` 12 个子命令；
  `form-check --ci` 外环 fail-closed 姿态（fail→1、unknown→2）。

### MCP daemon（`ward-mcp`）

- stdio 协议（官方 rmcp SDK），10 个工具：
  `spot / replay / catch_run / verify_full / form_check / spot_action /
  context_card / clusters / compat_check / intent_check`，全部 fail-open
  结构化返回。

### 集成与工程

- Claude Code PreToolUse/PostToolUse hooks（deny-with-reason 矩阵适配）；
- CI 四门禁：fmt / clippy `-D warnings` / 全量测试 / 覆盖率 ≥85%，
  外加 self-dogfood spot 与 jscpd 重复基线；
- Release 流水线（v* tag 触发）：版本一致性校验 → 质量门 → 5 目标矩阵
  构建 → 打包 → SHA256SUMS → 自动笔记 → GitHub Release。
