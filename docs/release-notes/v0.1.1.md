# Release v0.1.1

> 修复与验证版：一条命令安装、11 项意义验证 harness、三个"诚实裁决"缺陷修复。
> 本版主题是**让 Ward 能被真正用起来，并且让它不撒谎**。

## Highlights

- **一键安装器**：`curl …/scripts/install.sh | sh`——按平台下载发布资产、
  SHA256 校验、符号链接、自动注册 Claude Code（`claude mcp add`）/ Codex
  （`[mcp_servers.ward]`）/ Cursor（项目 `.cursor/mcp.json`），幂等可卸载；
- **意义验证 harness**：`scripts/verify-meaningful.sh` 11 项检查（已知案例
  召回/精度 + 对抗性语义），fail-closed 自检，接入 CI 每次 push 执行；
- **三个诚实性修复**（详见 Fixes）：Docker 假阳性、intent-check 崩溃、
  沙箱断网空缓存必失败。

## Breaking Changes

- 无。索引 schema 未变更，`.ward/config.toml` 无破坏性改动。

## Features

- `ward setup-hooks` 尚未引入（v0.2.0 提供）；本版安装器仅注册 MCP，
  不安装 git hooks。
- `ward form-check --ci`：外环 fail-closed 姿态（fail→exit 1、
  unknown→exit 2），advisory 模式保持 fail-open。

## Fixes

1. **Docker 守护进程假阳性**（F13）：`docker info` 客户端退出码为 0 但守护
   进程未运行时，旧代码误判"沙箱可用"，把连接失败当成测试失败。现改为
   校验 ServerVersion 实际输出，且 `Cannot connect to the Docker daemon`
   映射为 `unknown`（沙箱不可用，绝不 fake fail）。
2. **intent-check 崩溃**：单提交仓库 `HEAD^` 不存在时硬报错；现 fail-open
   为"未执行 + 原因"，退出 0。
3. **沙箱断网 + 空 cargo 缓存必失败**：外环裁决在开发机上永远红。现自动
   挂载仓库本地 `.cargo` 只读 + `CARGO_NET_OFFLINE=true`，让沙箱真跑测试
   成为可能。

## Testing / CI

- 新增 `meaningful-smoke` CI job（11 项 harness 每次 push 回归）；
- 新增 docker daemon 竞态、沙箱缓存挂载条件、缓存安全姿态断言等测试。
