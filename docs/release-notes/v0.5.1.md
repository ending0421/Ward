# Release v0.5.1

> hotfix（issue #5）：低特异度签名的精度崩塌。0.5.x 只出 hotfix——
> 这一版没有新功能，只修正一个被真实黄金集数据证伪的行为。

## Highlights

- **签名特异度（specificity）**：参数类型中**域类型**（非基础/标准库
  类型）的占比。基础类型签名（全 `u64`/`String`/`Int` 组合）的
  结构指纹退化成"带 N 个标量参数的函数"——issue #5 的 34 条黄金集
  标注 34/34 全部误报、任何阈值都无法挽回；
- **门禁语义修正**：查询特异度低于 `thresholds.specificity_floor`
  （默认 0.5）时，匹配**仍然返回给人类**（fail-open 不变），但
  等级封顶 Weak、`low_confidence: true`、并附"自动化门禁应忽略"
  说明——自动 gate 从此可以按构造忽略形状级误报；
- **双侧可见**：`SpotResult.query_specificity` /
  `low_confidence`、`SpotMatch.specificity`（命中符号自身的特异度）
  全部入 JSON——与黄金集/校准回路天然衔接（可按 (specificity,
  similarity) 联合定阈，本版不引入，避免指纹空间变动）。

## Fixes

1. 低特异度签名精度崩塌（#5）——见 Highlights；
2. 顺带修正：tree-sitter-swift 对无函数体声明用 ERROR 节点包裹
   （参数直接挂在包裹节点上）——特异度提取器按此容错，垃圾输入
   仍诚实返回 None（F3）。

## Breaking Changes

- 行为变化（有意为之）：低特异度查询的命中等级从 Strong 封顶为
  Weak。**迁移**：依赖 spot 强提示的自动化消费者请检查
  `low_confidence` 字段（或忽略 Weak）；人类工作流无感——匹配与
  相似度数值不变。

## Testing / CI

- 新增：五语言基础类型表分类（含容器递归：`Vec<ModelRect>` 是域
  类型、`Vec<u8>` 是基础）、零参/垃圾签名、ERROR 包裹容错、
  issue #5 e2e（低特异度=flag+永不 Strong；域类型查询保持完整分级）。
