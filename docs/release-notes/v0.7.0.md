# Release v0.7.0

> **边界契约里程碑**：把"Ward 核心与真实 gate 之间的消费者契约"补齐。
> 六个 issue（#6–#11）全部来自同一份 2 个月部署回测的现场数据，主题
> 一致：护栏在"无法诚实回答"时不得静默、在"常见路径"上不得昂贵、
> 在"决策已经做过"时不得重新审理、在"安装"时不得踩坏别人的 hook。

## Highlights

- **索引状态成为一等契约（#6）**：`spot` 不再自动创建空索引——
  "没有索引"现在以 `index_state: "missing"/"empty"` + exit 3 出现，
  再也不会伪装成"没有重复"。linked git worktree 无自有索引时
  **自动共享主 checkout 的索引**（提交内容逐字节一致，per-file 内容
  哈希仍按 worktree 文件校验），零配置零人工；结果带 `repo_root`
  与 `index_shared_from`，消费方不再需要手工反推路径锚点；
- **新鲜度升级契约（#7）**：`--max-staleness-commits/-days` 超出 →
  `stale_severe: true` + **exit 3**（无法诚实回答）；严重滞后时逐命中
  标注；普通滞后时自动检测"该命中在 HEAD 已删除"（坐标历史警告）；
  `ward stats` 头条显示索引新鲜度（as_of 距 HEAD 的 commit 数）；
- **常见路径变便宜（#8）**：`spot --quick` —— 低特异度签名（基础类型
  参数）**不碰索引直接回答**（`quick: true`），84% 的 gate 调用不再付
  全管道成本；低特异度谓词文档化为稳定 API，gate 可在 hook 内预筛；
- **ack 登记处（#9）**：`ward ack --against <hit> --reason "..."` 写入
  `acks` 治理表（schema v8，F1 重建保全）；spot **默认不再返回已 ack
  的命中**（`--show-acked` 可见）——一次决定不再在每个编辑点重新审
  理；posttooluse hook 自动回写 `ward-ack:`/`ward-converges:` 标记，
  **零 Agent 配合**，决策时刻闭环；
- **整合语义（#10）**：`--consumes <symbol>` 声明"本次编辑消费/整合
  该符号" → 命中降级为 `kind: consumed` 信息性提示并记录收敛事件；
  正在做去重的人不再被自己的护栏拦下；
- **安装不踩人（#11）**：`setup-hooks` 对已有 post-commit 采用
  backup-and-chain（原件存 `post-commit.pre-ward`，链式 fail-open），
  `--remove` 还原原件——git-lfs 这类既有 hook 不再被静默覆盖。

## Breaking Changes

- `SpotResult` 契约扩展：新增 `repo_root`/`index_state`/`symbol_count`/
  `stale_severe`/`stale_commits`/`quick`/`index_shared_from`（全部带
  serde 默认，旧 payload 可反序列化）；`search::spot` 签名改为
  `SpotOptions` 结构（Rust 消费方需迁移）；
- **exit code 3**：spot 在无索引/空索引/新鲜度地板被突破时退出 3——
  gate 必须把 3 当"先刷新再放行"，绝不能当"无重复"；
- 索引 schema v7→**v8**（acks 治理表）：F1 自动重建，治理数据保全；
- `spot` 不再自动创建索引（#6）：依赖旧行为的流程需先 `ward index`。

## Testing / CI

- 新增 e2e：unindexed=missing 且不建库、quick 路径不碰索引、worktree
  共享主索引、ack 抑制与 --show-acked、consumes 降级 + 收敛事件、
  新鲜度地板升级；cli_smoke：exit 3 契约、setup-hooks 链式安装/还原；
- hook 端到端冒烟：`ward-ack:` 标记 → 自动登记 → spot 不再返回该命中。
